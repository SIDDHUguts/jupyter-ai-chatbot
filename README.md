# 🤖 Advanced AI Chatbot for Jupyter Notebook & Python

A next-generation interactive AI chatbot and data analysis companion built for Jupyter Notebooks (`.ipynb`) and Python terminals.

---

## 🌟 Key Features

1. **🎨 Multi-Theme Visual UI (`ipywidgets` + CSS/HTML)**:
   - **Midnight Dark** (default slate & indigo theme)
   - **Clean Light** (crisp high-contrast modern light theme)
   - **Cyberpunk Glass** (neon cyan & violet obsidian glassmorphism)
2. **⚡ Quick Action Shortcuts Toolbar**:
   - `📊 Analyze Data` - Instant statistical breakdown of attached variables/dataframes.
   - `📈 Plot Chart` - Generates clean Matplotlib / Seaborn visualization code.
   - `🐛 Debug Code` - Spot bugs, edge cases, and runtime exceptions.
   - `⚡ Optimize` - Vectorization and memory profiling advice.
   - `🧪 Unit Tests` - Generates `unittest` suites.
3. **📎 Chat with Notebook Data & Variables (Context Injection)**:
   - Attach active DataFrames (`df.shape`, `df.head()`, `df.describe()`, column dtypes), NumPy arrays, dictionaries, or custom objects directly to the prompt context.
4. **▶️ In-Kernel Code Execution ("Run Last Code")**:
   - Execute Python snippets generated by the assistant directly in the active Jupyter kernel with a single button click.
5. **🌊 Real-Time Streaming Generation**:
   - Live token-by-token streaming in both Jupyter notebook and terminal modes.
6. **💾 Conversation Session Persistence**:
   - Save conversation threads to `sessions/<name>.json` and reload or fork conversations at any time.
7. **🔑 Dual Backend Engine**:
   - **Offline Smart Mode**: Works 100% offline out-of-the-box with no API key or setup needed.
   - **Google Gemini 2.5 API**: Connect your `GEMINI_API_KEY` in the UI to unlock Gemini 2.5 Flash / Pro reasoning.

## 🚀 Quick Start

### 1. Launch in Jupyter Notebook
Open [`chatbot_notebook.ipynb`](file:///C:/Users/samee/.gemini/antigravity-ide/scratch/jupyter_chatbot/chatbot_notebook.ipynb) in JupyterLab, VS Code, or Antigravity IDE. Select the virtual environment at `.\.venv\Scripts\python.exe` as the kernel and run the cells.

### 2. Run Interactive CLI in Terminal
```powershell
cd C:\Users\samee\.gemini\antigravity-ide\scratch\jupyter_chatbot
.\.venv\Scripts\python.exe run_chatbot.py
```

CLI Commands:
- `:clear` - Clear chat history
- `:persona <name>` - Switch persona
- `:save <name>` - Save session to `sessions/<name>.json`
- `:load <filepath>` - Restore a saved session
- `:attach <name>=<value>` - Attach a variable to context
- `:exit` - Quit

### 3. Run Self-Tests
```powershell
.\.venv\Scripts\python.exe run_chatbot.py --test
```
